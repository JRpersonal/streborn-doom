DOOM on a Bose SoundTouch Portable running STR. Download `str-doom` for your computer and run it with the speaker's address; see the README for the keys.

| File | For |
|---|---|
| `str-doom-windows-amd64.exe` | Windows |
| `str-doom-darwin-arm64` / `str-doom-darwin-amd64` | macOS (Apple silicon / Intel) |
| `str-doom-linux-amd64` / `str-doom-linux-arm64` | Linux |
| `doom-str`, `doompad` | the speaker side, already inside `str-doom` |

The programs are not code-signed: Windows may show a SmartScreen warning, and on macOS run `xattr -d com.apple.quarantine str-doom-darwin-*` once.
